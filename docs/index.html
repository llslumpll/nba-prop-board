How a projection is made

  • Minutes first. Recent minutes (recency-weighted), scaled so each team's rotation adds up to about 240, which hands out minutes when teammates are out. Back-to-backs and likely blowouts trim starters.
  • Then per-minute rates, blending this season with the last two by games played: more games this season means more weight on this season.
  • Then context: opponent pace, home/road, rest. Each one is small and capped, and shown in the "why".
  • Then a range, not just a number: rebounds, assists and threes use a count distribution; points and combos a normal curve. That range turns into a chance for each line.
  • Tested before launch on the full 2025-26 season it was never tuned on: average points miss 5.099 vs 5.313 for a season average, rebounds 1.998 vs 2.042, assists 1.544 vs 1.579. Beating a season average isn't the same as beating a sportsbook; that is measured live on History.
